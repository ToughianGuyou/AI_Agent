# 李博杰

## 概述

李博杰，《深入理解 AI Agent：设计原理与工程实践》作者，Pine AI 首席科学家。他在中国科学技术大学（国科大）持续开设 AI Agent 实践课程，在图灵《AI Agent 实战营》进行系列技术讲座。他的核心主张是：Agent 设计应从"感觉驱动"变成"原则驱动"，好的设计原则应能穿越模型迭代周期。

## 核心贡献

### Pine AI：第一个处理金钱事务的长程通用 Agent

在 Pine AI，李博杰和团队打造了据称第一个能够自主与真人交互、并可靠独立处理涉及金钱的敏感复杂长程任务的通用 Agent——替用户打电话协商账单、与商家交涉退款投诉、取消订阅，全程无需人工接管。这类任务动辄几十轮交涉，任何一步出错都会造成真金白银的损失。

### 架构原则的工程先验

李博杰的核心论点之一是"实践在前，命名在后"：Pine AI 在 Skill、Harness、Loop Engineering 等概念流行之前就已在生产中使用对应方法：

- **Skill 之前**：动态加载提示词解决提示词无限膨胀，命令行执行工具解决工具列表膨胀，系统状态栏解决 Agent 不感知环境
- **Harness 之前**：类似 Claude Code 的方法解决模型工具调用的不稳定、幻觉、危险操作等问题
- **Loop Engineering 之前**：提议者-审核者（proposer-reviewer）方法解决模型过早认为任务完成

### Whisper Coding 方法论

李博杰提出并实践"口述式协作"（Whisper Coding）：以语音 Agent 为协作工具，通过口述→调研→讨论→修改的迭代循环完成写作和编程。正常说话速度约为打字的四倍，语音带宽远高于打字。本书本身即采用此方法完成。

## 方法论特征

- 强调"用科学的方法论做工程"——评估是这套方法论的地基
- 主张保持高要求的真实业务场景，以倒逼架构原则的形成
- 倡导开源知识传播——全书正文、配图和 92 个配套实验全部开源

## 证据与来源

主要来源为 [[深入理解 AI Agent]] 引言和全书各处关于 Pine AI 实践的自述。作者自身经验和观点属于第一手来源，但部分实践细节无法独立验证。

## 分歧与不确定性

- "Pine 是第一个能自主处理涉及金钱的通用 Agent"属于作者自述，缺乏第三方独立验证
- 各头部公司在 Harness 工程上的实践时间线目前没有公开的交叉证据
