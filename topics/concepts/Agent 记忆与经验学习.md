# Agent 记忆与经验学习

## 概述
Agent 记忆用于在任务步骤、并发任务或多次会话之间保存事实、进度、策略和失败经验。

## 核心内容
- 工作记忆支持当前步骤，结构化记忆保存任务状态，语义或经验记忆支持跨任务复用。
- 隔离不同任务的记忆可减少串扰；摘要和检索控制上下文增长。
- 环境轨迹可用来学习策略或训练世界模型，但错误经验也可能被固化。

### 用户记忆的四种存储格式

[[深入理解 AI Agent]] 第 3 章给出了渐进的四种记忆格式，代表了粒度和结构复杂度的递进：

- **Simple Notes**：每条记忆是最小不可再分的事实，O(1) 操作但信息关联性完全丢失
- **Enhanced Notes**：保存为含完整上下文的段落，保留叙事结构但存储冗余、更新复杂
- **JSON Cards**：三层嵌套结构（类别→子类别→键值对），支持部分更新但刚性结构损失多维性
- **Advanced JSON Cards**：从信息存储到知识管理——每条记录加入 backstory、person、relationship 和时间戳，用于消歧，代价是维护成本高

实践中的选择标准：关键且少量的数据用 Advanced JSON Cards 保证可检索性；大量且非关键的对话事实用 Simple Notes 降低成本；多数生产系统采用混合模式。

### User as Code：可执行代码作为记忆介质

User as Code 把记忆介质从文本换成可执行代码：两阶段设计——记忆阶段（每次会话后 LLM 把事实追加到只增日志），结构化阶段（周期性地从完整事实日志重新生成带类型的 Python dataclass）。这种"预写日志 + 周期性检查点"的数据库经典设计首次被用到 LLM 记忆上，使得聚合统计（"我去年出了几次国？"）和冲突发现（用药 vs 过敏交叉比对）变成确定性代码而非 LLM"心算"。

### 三层次记忆评估框架

- **第一层：基础回忆**——准确存储和检索结构化无歧义信息
- **第二层：多会话检索**——跨对象、跨时间的多会话信息综合推理
- **第三层：主动服务**——综合跨会话信息提供预见性主动帮助

### 持续进化闭环

第 8 章将记忆延伸到经验学习：Agent 需要从运行轨迹中持续进化——记录运行证据→验证结果与过程→从多条轨迹中提取共性→决定更新知识、指令、程序还是模型参数。四种更新载体：(1) 经验知识库（事实、经验规律）、(2) Prompt 与 Skill（可语言化的策略）、(3) 程序与 Harness（确定性流程和约束）、(4) 模型参数（高维感知和隐式策略）。"保存经历不等于从经历中学习"——学习发生在系统主动完成"评价、对照、归纳、验证"之后。

## 证据与来源

## 分歧与不确定性
更多存储不等于更好记忆；关键问题是形成、筛选、更新、冲突消解和遗忘。
