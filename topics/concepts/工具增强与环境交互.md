# 工具增强与环境交互

## 概述
Agent 通过搜索、浏览器、代码、API、数据库或物理设备改变外部状态，并依据反馈继续规划。

## 核心内容
- 工具 schema 和确定性接口决定 Agent 能观察与行动的边界。
- Agentic RAG 把检索从一次调用变成分解、导航和证据充分性检查。
- 世界模型可以模拟环境以降低真实交互成本，但会引入模拟偏差。
- 物理闭环通常仍需要人类处理材料和设备。

## 证据与来源
见 [[Using a GPT-5-driven autonomous lab to optimize protein synthesis]]、[[Unlocking dependable responses with Agentic RAG]]、[[Superintelligent Retrieval Agent]]、[[Qwen-AgentWorld]]。

## 分歧与不确定性
更复杂的工具链可能提高能力，也可能扩大权限、提示注入和错误传播面。
