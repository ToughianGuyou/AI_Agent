# 科学发现 Agent

## 概述
科学发现 Agent 把文献、数据库、假设生成、实验设计、数据分析和验证连接成可迭代流程。

## 核心内容
- Multi-Agent 可以让生成、反思、排名和验证角色互相制衡。
- 自主实验室将建议转成机器可执行实验，再把结果反馈给模型。
- 医疗和生命科学必须保持专家审查、确定性数据接口与安全边界。

## 证据与来源
[[Accelerating scientific discovery with Co-Scientist]] 展示假设竞争；[[Using a GPT-5-driven autonomous lab to optimize protein synthesis]] 展示物理闭环；[[SymptomAI]] 展示大样本对话访谈。

## 分歧与不确定性
自动评测的“好假设”不等于真实发现；窄任务成功不能外推到开放科学或临床安全。
