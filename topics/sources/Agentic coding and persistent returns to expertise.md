# Agentic coding and persistent returns to expertise

## 核心摘要
报告以隐私保护方式分析约 40 万个 Claude Code 会话和约 23.5 万名用户，研究 Agent 编码任务、成功率与领域专业知识之间的关系。

## 关键论点与证据
- 观察期为 2025-10 至 2026-04；调试会话占比从 33% 降到 19%。
- 运行软件由 14% 升到 21%，写作与数据分析合计约从 10% 升到 20%。
- 按自由职业职位代理估算，典型任务价值平均上升约 27%。
- 在编码任务上，不同职业平均成功率接近软件工程师；领域专长越高，每条指令完成的工作越多。

## 与现有知识的关系
表明 Agent 更可能改变“谁负责计划、谁负责执行”的分工，而不是消除领域知识的价值。

## 待验证问题
只覆盖交互式 Claude Code；职业、成功和价值依赖分类器与代理指标，不能解释为因果生产率。
