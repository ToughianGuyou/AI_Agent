# The Shift to Agentic AI: Evidence from Codex

## 来源信息
- 机构：[[OpenAI]]
- 日期：2026-06-25
- 类型：arXiv 论文、官方经济研究
- 论文：https://arxiv.org/abs/2606.26959
- 官方页：https://openai.com/index/how-agents-are-transforming-work/

## 核心摘要
OpenAI 用 Codex 产品遥测研究用户如何从短对话转向长程、并行和跨职能的 Agent 工作。

## 关键论点与证据
- 2026 上半年活跃用户增长超过 5 倍；超过 10% 的用户每周管理至少 3 个并发 Agent，26.6% 使用 skills。
- 至少发起过一次预计超过 30 分钟、1 小时和 8 小时人类工作量任务的个人用户分别为 80.6%、70.2% 和 25.6%。
- P99 日活用户每天产生超过 60 小时并行 Agent 回合。
- OpenAI 内部工程师约 99% 的输出 token 来自 Codex，研究岗位中位使用量相对 2025-11 增长约 56 倍。

## 与现有知识的关系

## 待验证问题
预计人类耗时和 token 是代理指标；内部高强度用户不代表普通用户，也不能直接证明经济生产率。
