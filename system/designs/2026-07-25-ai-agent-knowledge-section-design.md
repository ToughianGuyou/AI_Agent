# 2026 AI Agent 知识板块设计

## 目标

在 Obsidian Vault 中建立可持续维护的 AI Agent 知识板块，帮助用户沿学习路径理解 2026 年主要 AI 机构在 Agent 领域的研究进展，同时保留每项结论的原始出处。

本轮统计截止日期为 2026-07-25。2026 年尚未结束，因此成果不得表述为全年完整清单。

## 收录范围

优先覆盖：

- Anthropic
- OpenAI
- Google 与 Google DeepMind
- DeepSeek

在存在实质性 Agent 研究成果时，扩展到 Meta、Microsoft、Alibaba、ByteDance、Moonshot、xAI 等机构。

允许的来源类型：

- 正式发表论文
- arXiv 等可信预印本
- 官方技术报告
- 官方系统卡
- 能提供独有技术细节的官方研究博客

搜索结果页、二手新闻和无可核验出处的汇总不作为长期知识证据。机构归属、发布日期和论文内容应优先通过论文原文、官方研究页面或正式出版页面交叉核验。

## 信息架构

采用“学习路径 + 来源档案”的混合结构。

### 学习地图

建立一份 AI Agent 学习地图，按以下顺序组织知识：

1. Agent 基础与系统架构
2. 推理、规划与任务分解
3. 工具使用、环境交互与计算机操作
4. 记忆、上下文管理与长程任务
5. Multi-Agent 协作
6. 评测、可靠性与安全

学习地图只保留稳定概念、先修关系和推荐阅读顺序，不复制来源页的完整摘要。

### 来源页

每份入选材料建立独立来源页，至少包括：

- 标题、作者或机构、发布日期与来源类型
- 论文或官方页面链接
- 核心摘要与关键技术贡献
- 实验、数据或主要证据
- 局限性、不确定性和待验证问题
- 与其他概念、机构和来源的 Wiki 链接
- 对学习 AI Agent 的价值与建议阅读位置

### 概念与实体页

只为会被多个来源引用、值得长期维护的概念和机构建立页面，避免为每个术语机械建页。

### 年度综合页

建立“2026 年 AI Agent 研究综述”，按研究方向比较不同机构的路线、共同趋势、关键分歧与证据强度。综合判断与来源直接陈述必须明确区分。

## 检索与筛选

检索同时覆盖机构官方研究站点、论文数据库和作者发布页。候选材料需满足：

1. 首次公开或正式发表时间位于 2026-01-01 至 2026-07-25；
2. 与自主规划、工具调用、环境交互、长程任务、Multi-Agent、Agent 评测或安全直接相关；
3. 存在可访问、可追溯的原始来源；
4. 对理解方法、系统能力或评测结果有实质信息，而非单纯产品公告。

边界材料可纳入，但必须在来源页中解释其与 Agent 的关系。仅更新版本而非 2026 年首次公开的旧论文不计入 2026 年论文清单。

## 数据流与写入

1. 按 Vault Schema 完成现有 `Clippings/` 的增量检测与必要 Ingest。
2. 形成候选清单并核验日期、归属与原始链接。
3. 依据相关性、来源质量和学习价值筛选。
4. 写入来源页，再建立概念、实体和综合页。
5. 更新 `topics/index.md`、`system/source-state.json` 与追加式日志。
6. 执行轻量 Lint；达到 Schema 阈值时执行深度 Lint。
7. 验证 Frontmatter、JSON、Wiki 链接、索引覆盖和 Git diff。
8. 释放写入锁，并仅提交本轮涉及的文件。

## 异常与不确定性

- 无法确认发布日期或机构归属的候选不写成确定事实。
- 官方页面与论文元数据冲突时保留双方证据并标记争议。
- 页面暂时无法访问时记录缺口，不用二手报道替代原始证据。
- 2026 年后续新增研究不在本轮范围内，综合页必须保留截止日期。
- 不修改 `Clippings/`，不覆盖用户现有的 `CLAUDE.md` 修改。

## 验收标准

- 至少覆盖 Anthropic、OpenAI、Google/Google DeepMind、DeepSeek 的检索结果；若某机构没有符合条件的材料，明确记录“未检得”，不得用旧材料填充。
- 每个入选条目都能追溯到论文或官方原始页面。
- 用户可以从学习地图进入来源页、概念页、机构页和年度综述。
- 所有新增页面具有合法 Frontmatter，索引覆盖完整，Wiki 链接有效或被明确标为有意未解析。
- `Clippings/` 无 Agent 修改，用户原有工作树修改得到保留。
- Lint 报告、来源同步计数和本地提交结果可审计。
